# 🚗 Driving License Management System (DVLD)

A comprehensive desktop application built with **C# Windows Forms** and **SQL Server** designed to manage all operations related to driving licenses, local/international applications, test appointments, and applicant records.

---

## 🛠️ Tech Stack & Architecture

* **Language:** C# (.NET Framework)
* **UI Framework:** Windows Forms (WinForms) with custom UserControls
* **Database Management System:** SQL Server 2022
* **Architecture:** Multi-tier Architecture (Presentation Layer, Business Logic Layer - BLL, Data Access Layer - DAL)
* **Version Control:** Git & GitHub

---

## 🌟 Key Features & Modules

* **People Management:** Complete CRUD operations for managing person records, national numbers, images, and contact information with custom search filters.
* **Local Driving License Applications:** Manage applications through all stages (New application, test appointments, vision/written/street tests, and final license issuance).
* **International Driving Licenses:** Issue and track international driving licenses based on local licenses.
* **Renew & Replace:** Handle license renewals, and replacements for lost or damaged licenses.
* **Detained Licenses:** Manage detained and released licenses with fine calculations.
* **Users & Permissions:** Secure login system with role-based user management and password updates.
* **Reusable Components:** Extensive use of custom UserControls for modular and clean UI design.
